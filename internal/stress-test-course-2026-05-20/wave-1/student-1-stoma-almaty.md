### Reality-check (через `reality-check-metrics`)

**Применение SWITCH по профилю** (правильно для LOCAL_SERVICE HIGH_TICKET):

- Формула классическая `CPL = Маржа × CR / ROAS`, но с **тройным CPL** для длинного цикла (PROMPT-1 строка 174 + reality-check-metrics строка 184).
- Чек 2000 USD × Маржа 35% = **CAC = 700 USD предельный**
- CR (LOCAL_SERVICE стоматология) — бенчмарк 25-40%, бери **30%** (середина)
- Целевой ROAS для HIGH_TICKET — **5** (бенчмарк), но клиент новый — реалистично 3-4 на первый цикл
- Предельный CPL_лид (заявка/звонок) = 700 × 0.30 / 4 = **52.5 USD**
- Cost per consultation (доведение до состоявшегося визита) — отдельная метрика

**Реалистичный стартовый CPL для LOCAL_SERVICE СНГ:** 5-15 USD. Но для HIGH_TICKET_LOCAL_SERVICE медицина — выше, 15-50 USD на заявку, 50-150 USD на состоявшуюся консультацию.

Множитель по гео: KZ → **× 0.7-1.0** (CPM зона $2-6).

**Вердикт:**
- Если план клиента 15-30 USD CPL_заявки → сценарий **A** (план реалистичный)
- Если ученик хочет «3$ за лида» (как часто говорят локальщики) → сценарий **C**
- Тройной CPL: заявка / замер (бесплатный, 1-2 неделя) / договор (3-4 неделя)

**🔴 БАГ #1 — reality-check НЕ делает раскладку «тройной CPL» автоматически для HIGH_TICKET_LOCAL_SERVICE.** В SKILL.md (строка 184) сказано «тройной CPL для циклов 60-180 дней», но в шаге расчётов и в шаблоне промпта (строка 217-243) этого нет — есть только classic CPL. Бот считает один CPL_лид и забывает про CPL_замер и CPL_договор. Для стомы это критично — клиент думает «у меня лид 30$ — норм», а реально консультация состоится у 50% и договор подпишут 25-35% от консультаций → cost per договор будет 300+ USD, не 30.

**🔴 БАГ #2 — нет автоматического расчёта LTV для retention.** Для стомы реальный LTV пациента: имплант + повторные процедуры (кариес, чистки, второй имплант через 5-7 лет, члены семьи) = 5,000-15,000 USD за 5 лет. В `reality-check-metrics` строки 32-46 указано про retention для LOCAL_SERVICE, но `worked example` только для барбершопа. Для стомы примера нет → бот может посчитать по чеку первого визита (2000 USD) и завалить экономику до сценария B/C, тогда как с LTV-моделью клиент чувствует себя «в плюсе».

## ЭТАП 3: ВТОРОЙ РЕСЕРЧ — нужен ли?

### Моё решение как ученика: **ДА, нужен.**

**Обоснование:**

1. **Языковая раскладка** — DR выдал 25 URL на русском, 2 URL на казахском. По правилу PROMPT-2 строка 196-201: «если на одном языке <30% → пометь "языковой перекос" и добор второй волной». Казахский = 7% → языковой перекос. Нужна 2-я волна на казахском.

2. **Покрытие 9 типов цитат** — после Шага 2 типы:
   - B (боль): 8 цитат ✅
   - F (страх): 5 цитат ✅
   - W (желание): 4 цитаты ✅
   - $ (деньги): 7 цитат ✅
   - T (время): 3 цитаты ⚠️ (норма STANDARD = 5)
   - D (доверие): 6 цитат ✅
   - X (барьер действия): 2 цитаты 🔴 (GAP — нужен добор)
   - A (альтернативы): 4 цитаты ✅
   - S (соцдоказ): 3 цитаты ⚠️ (норма STANDARD = 5)
   - [!] (амбиция, волна М): 1 цитата 🔴 (норма STANDARD = 3-5, блокер для большого прохода)

3. **[!] амбиции = 1** — это блокер по PROMPT-2 строка 429: «ЕСЛИ [!] амбиций = 0 → блокер для Чата 1, нужен дозабор источников амбиций». 1 цитата — на грани, лучше добрать через YouTube-кейсы пациентов «как я поставил импланты и теперь улыбаюсь».

4. **Подсегмент виниры** — все цитаты про импланты, цитат про виниры почти нет. Виниры — отдельная аудитория (часто женщины 25-40, эстетика), нужен отдельный отбор источников.

**Вторая волна Чата 2:**
- Шаг 2 повторно по 5-7 URL: казахскоязычные источники (forum.spruce.kz казахская секция, TG-чаты на казахском, Google Maps казахских отзывов) + YouTube-видео «получил/получила виниры» + дополнительные URL для типов X и [!]
