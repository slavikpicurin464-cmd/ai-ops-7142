## Контекст и почему это болевой тест

GREY_NICHE vape — это **ниша, для которой курс прямо говорит «канал Meta закрыт регуляторно»** (KONVEYER-LOGIKA §3.9 строка 705-707):

> Если ниша GREY_NICHE не проходит Meta-policy (vape во всех гео / casino без authorization / nicotine pouches) — курс ТОЛЬКО про Meta. Если для конкретной серой ниши Meta невозможен по политике — это значит конвейер курса для неё не применим целиком. Помечай ученику: «канал Meta для этой ниши закрыт регуляторно, нужен другой канал — вне охвата курса». **Не предлагай альтернативные каналы (Telegram Ads / Google Ads / TikTok Ads / CPA-сети / инфлюенсеры) как часть конвейера — это отдельная экспертиза.**

Но в analytics-deep-dive (раздел 3.8.2) есть отдельная подсистема под TG Ads — то есть курс **частично** умеет TG Ads, но только на этапе аналитики. Это создаёт **внутреннее противоречие курса**, которое всплывёт уже на Этапе 1.5.

Тест проверяет:
1. поймёт ли конвейер на Этапе 1 / 1.5 что Meta закрыт?
2. правильно ли он остановит ученика и **что предложит дальше**?
3. что произойдёт если ученик скажет «всё равно прогоняем, потом разберёмся»?

Спойлер: курс ловит проблему через meta-policy-checker, но **не имеет чистого fallback-сценария** для vape — конвейер не предусматривает работу под TG Ads (только аналитика). Это БАГ К28-К31, см. секцию «Новые баги».

### 1.3 Reality-check (skill `reality-check-metrics`)

Считаю предельный CPL для ECOM по формуле курса (АНАЛИТИКА-LOGIKA: для ECOM не маржа × конверсия, а ROAS_break-even через AOV × маржа × повтор):

- AOV первой покупки = $40
- Маржа 35% (vape devices наценка ~50%, расходники ~30%, blended ~35%) → $14 валовой прибыли с заказа
- Repeat 60% за 90 дней с AOV расходников $12, маржа 30% → $3.6 валовой прибыли с повтора
- **LTV 90 дней = $14 + 0.6 × $3.6 = $16.2 на привлечённого покупателя**
- ROAS break-even = 1/(валовая маржа/AOV) → 2.5× на первой покупке. Plus repeat → ROAS break-even с учётом LTV = ~2.0× за 90 дней
- Целевой CAC = LTV × 0.5 = $8 (если хотим payback < 90 дней с поправкой на operational)

### Реалистичный CAC по бенчмарку (важно — НЕ Meta-бенчмарк):

| Канал | Реалистичный CAC | Применимо для vape? |
|---|---|---|
| Meta CPM × CTR × конверсия лендинга | ~$8-15 для ECOM KZ AOV $40 | **НЕТ — Meta запрещает vape** |
| TG Ads (CPM-модель) | ~$3-6 за тёплый клик на @bot, конверсия в покупку 2-4% → CAC $40-150 | **ДА, но дорого для AOV $40** |
| TG Ads через тематические каналы (CPS-модель с админами) | $5-12 за заказ через каналы про vape KZ/UZ | **ДА — наиболее реалистично** |
| Партнёрки vape-шопов | $3-5 за заказ через инфлюенсеров | вне курса |
| OLX listing + органический поиск | $0 (но без таргета) | органика, не таргет |

**Вердикт reality-check:**
- Целевой CAC $8 → **на TG Ads недостижим** при AOV $40. Реалистичный CAC через TG Ads = $20-40.
- Чтобы экономика сошлась, нужно либо: (а) поднять средний чек первой покупки до $80+ через бандлы, либо (б) повысить repeat-rate до 80% за 90 дней, либо (в) сменить модель на подписку (картриджи каждый месяц).

**Бюджет $1,500/мес → $1,500 / $25 (реалистичный CAC TG Ads) = 60 покупок/мес**. На 2 гео (KZ + UZ) — это ~30 покупок на гео, что **ниже статпорога** для оптимизации.

**Я ученик-middle уже на этом этапе говорю клиенту:**

> «Реальность не сходится. Целевой CPL $8 на TG Ads — недостижим. Реалистичный CAC $20-40. С бюджетом $1,500/мес получится ~60 покупок/мес на 2 гео — это ~30 на гео, мало для оптимизации. Три варианта:
> 1. Поднять средний чек первой покупки через бандлы (устройство + 5 жидкостей за $80-100) — экономика сойдётся при CAC $25
> 2. Сменить модель на подписку картриджей ($15-20/мес) — повышаем LTV до $60-100 за 6 мес, тогда CAC $25 окупается
> 3. Снизить аппетиты — работаем на 1 гео (KZ как более ёмкий), полный бюджет на него, целимся в 60 покупок/мес на одной географии»

Это правильный выход reality-check. Клиент выбирает вариант **1+3** — бандлы + только KZ на первом цикле, UZ запускаем во втором цикле когда экономика подтвердится.
