### 1.2 BLENDED-РАСЧЁТ (фикс волны О, V11)

**Чат 1 считает blended маржу:**

Маржа после переменных по тарифам:
- Трип-вайр $99 → маржа $50 (50%)
- Основной $299 → маржа $135 (45%)
- Премиум $899 → маржа $360 (40%)

**Blended маржа на 1 закрытого клиента (с upsell-чейном):**
- Трип-вайр $50 × 100% = $50
- Upsell основной $135 × 14% (фактическая конверсия) = $18.9
- Upsell премиум $360 × 5% = $18

**Cumulative blended маржа на 1 закрытого клиента (Фикс 11 апсейл): $86.9**

**Чат 1 применяет фикс 11 — Cumulative LTV:**
> ВАЖНО: В апсейл-цепочках $99→$299→$899 нельзя считать CPL только по первой покупке (тогда $50 × 6% = $3 CPL). Считаем по cumulative LTV: $86.9 × 6% = **$5.2 предельный CPL по Cumulative LTV**.
>
> Если бы считали только по трип-вайру — упустили бы 73% реальной маржи ($86.9 vs $50), что в 1.7× занижает реалистичный CPL.

## НОВЫЕ БАГИ ВОЛНЫ 3 (фаза 3)

### БАГ Н1 — TG Ads для русскоязычной диаспоры USA
Чат 1 не предложил TG Ads как альтернативу/дополнение для русскоязычной диаспоры. По KONVEYER — Meta default. Это не баг по умолчанию (правило Игоря 2026-05-18), но для USA-диаспоры специфики стоит проговаривать в Reality-check.

**Приоритет:** P3 (low). Меta работает для USA-диаспоры (волна 1 проверено), это нюанс.

### БАГ Н2 — Конверсия 6% по верху воронки vs после квалификации
Чат 1 принял CRM-конверсию 6% без уточнения «по верху воронки (просто лид → оплата)» vs «после квалификации (вебинар → оплата)». Эти 2 цифры отличаются в 3-5× и критичны для прогноза CPL.

**Приоритет:** P2 (medium). Усилить опросник п.5 — добавить уточнение «конверсия по верху» vs «после квалификации».

### БАГ Н3 — meta-launch-checklist не выделил 3-tier value events для апсейла
Стандартный чек-лист «iOS 14+ priority events 8 шт» не покрывает кейс «3 разных тарифа с разной маржой». Нужно: для INFOBIZ-школ с тарифной лестницей — отдельные value-events на каждый тариф.

**Приоритет:** P1 (high). Добавить в meta-launch-checklist раздел «INFOBIZ с тарифной лестницей — 3-tier Purchase events».

### БАГ Н4 — UTM Apps Script не покрывает апсейл-цепочку
Стандартный шаблон UTM не различает «tripwire / standard / premium» в utm_content для апсейл-цепочки. Аналитика Чата 4 не видит апсейл-воронку по UTM.

**Приоритет:** P2 (medium). Добавить шаблон UTM для INFOBIZ-школ с тарифной лестницей.

### БАГ Н5 — Валютная локализация в крео для multi-geo
Чат 1 при выводе позиционирования не уточнил — нужна ли валютная локализация для каждого гео ($/₽/₴/Br/тенге). По матрице для USA-диаспоры $ есть, для СНГ — ₽ или нейтральные «доходы 50-150К» без валюты.

**Приоритет:** P2 (medium). Добавить в Бриф 3 поле «валюта в крео» по гео.

### БАГ Н6 — Цитата [T1] близка к жертве
«Нет времени даже на 30 минут учиться» — близко к маркеру жертвы. Я правильно поставил инструмент в D.0, но в Карте смыслов цитата осталась. Нужно: чёткая граница «BACKGROUND-цитата для понимания» vs «материал для крео».

**Приоритет:** P3 (low). Я middle, отфильтровал, но junior мог бы пропустить.

### БАГ Н7 — Граница STANDARD/PRO нечёткая на бюджете $2,500
$2,500/мес — на верхней границе STANDARD ($500-3000). На $3,000 уже PRO. Жёсткий пересчёт сегментов между режимами создаёт «обрыв».

**Приоритет:** P3 (low). Можно добавить «pre-PRO» подкатегорию ($2,000-3,000) с правилом «можно 3 сегмента + 4-й сегмент в LATER».

### БАГ Н8 — Нет INFOBIZ_INCOME_PRESET в meta-policy-checker
Скил работает по общим Категориям 2 + 5. Для INFOBIZ с обещанием дохода нет отдельного блока с готовыми заменами «заработай X → у выпускников разный темп». Я переформулировал руками.

**Приоритет:** P1 (high). Добавить INFOBIZ_INCOME_PRESET — частый сценарий курса.

### БАГ Н9 — Нет INFOBIZ_INCOME_AUDIT_LAYER (аналог CRISIS-AUDIT-LAYER)
Для CRISIS_EXPERT есть отдельный layer C1-C8 — для INFOBIZ с обещанием дохода нужно аналогичное.

**Приоритет:** P1 (high). Добавить INFOBIZ_INCOME_AUDIT_LAYER в meta-policy-checker.

### БАГ Н10 — Формулировка «50-150К через 3-6 мес» — пограничный риск

**Приоритет:** P1 (high). Усилить логику meta-policy-checker — конкретные цифры дохода всегда 🟡, даже с диапазоном и оговоркой «у выпускников разный темп».

30 крео руками = 30+ минут. Нет батч-режима.

Чат 3 не предложил автоматически разделить пачку «крео под СНГ» и «крео под USA-диаспору с AI DISCLOSURE». Делал руками.

**Приоритет:** P2 (medium). Усилить логику — каждое 🟡 крео в архиве с явным «требуется sign-off клиента ДО запуска».
