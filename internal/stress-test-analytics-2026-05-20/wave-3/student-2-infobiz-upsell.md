## Запрос 1. «Посчитай cumulative LTV апсейл-цепочки $99→$299→$899»

(Фикс 11 — payback для апсейл-цепочки; Фикс 24 — маржа диапазоном)

**Тип revenue:** апсейл-цепочка → формула `cumulative LTV = Σ (выручка шага × вероятность шага × маржа)`.

**Маржа не задана клиентом** → `[ГИПОТЕЗА: маржа INFOBIZ-курсов 40-70% — уточни у клиента]`. Считаю в двух сценариях.

**Вероятности перехода (фактические за период):**
- Step 1 (вошёл в воронку): 100% (по определению — это базовый покупатель)
- Step 1 → Step 2: 95/380 = **25.0%**
- Step 2 → Step 3 (от тех, кто взял Step 2): 28/95 = **29.5%**
- Step 1 → Step 3 (от всех покупателей Step 1): 28/380 = **7.4%**

**Cumulative выручка на одного покупателя Step 1 (БЕЗ маржи, gross):**

```
gross LTV = $99 × 1.0 + $299 × 0.25 + $899 × 0.074
         = $99 + $74.75 + $66.53
         = $240.28 / покупатель Step 1
```

Обратная проверка: $240.28 × 380 покупателей = $91 306. По заданию выручка $91 197 → расхождение $109 (0.12%) — это округления при пересчёте 28/380 = 0.0737 vs 0.074. **Сходится.**

**LTV с маржой — два сценария:**

| Сценарий | Маржа | LTV / покупатель Step 1 |
|---|---|---|
| Нижний (worst-case) | 40% | $240.28 × 0.40 = **$96.11** |
| Верхний (best-case) | 70% | $240.28 × 0.70 = **$168.20** |

**Внимание на «дозревание»:**

Когорты декабрь-январь (5-6 месяцев в воронке) показывают upsell-конверсию 25-32% Step1→Step2. Когорты март-апрель (1-2 месяца) — 11-20%. Это **классическое дозревание INFOBIZ-апсейла**: реальная финальная конверсия видна только через 90-180 дней от подписки.

Значит фактические 25% Step1→Step2 за общий период — **занижены** для свежих когорт. Через 90-180 дней март-апрель должны подтянуться к 25-30%. Если этого не произойдёт — продукт или воронка деградирует.

**Промежуточный вывод по LTV:** $96-168 / покупатель Step 1 в зависимости от маржи. Это **нижняя оценка** — реальный LTV через 360+ дней может быть выше за счёт ещё не дозревших когорт и повторных покупок Step 2/Step 3 (которые сейчас не учтены — данные не дал).

## Запрос 2. «Юнитка проекта. ARPU? CAC? Payback?»

(Фикс 10 — payback для разовых; Фикс 11 — payback для апсейл)

**Уточнение для middle:** ARPU здесь = средняя выручка с покупателя Step 1 (без апсейла). Это разовая покупка → payback в долях, не в месяцах. Для cumulative payback (с апсейлом) — формула «апсейл через N мес».

**Шаг 0 — определение типа revenue:**
- Step 1 базовый ($99) — разовая покупка, payback в долях
- Cumulative цепочка $99→$299→$899 — апсейл через N мес → payback в месяцах

**Расчёт основных метрик:**

```
Spend: $18 000 (всего за 150 дней)
Step 1 покупателей: 380
Step 2 покупателей: 95 (из тех же 380)
Step 3 покупателей: 28 (из тех же 380)
```

**ВНИМАНИЕ — атрибуция media mix:** $18 000 — это, по-видимому, только Meta paid (70% mix). Если включать организку — нужен time-cost. Уточняю отдельно ниже. Здесь считаю CAC от $18 000 как paid-only.

**ARPU (Average Revenue Per User, на покупателя Step 1):**
```
ARPU gross = $91 197 / 380 = $240.0 / покупатель Step 1
```

(Это та же gross LTV из Запроса 1. Round-trip совпадает.)

**CAC:**

```
CAC = $18 000 / 380 = $47.37 / покупатель Step 1
```

Обратная проверка: $47.37 × 380 = $18 001 ≈ $18 000. Сходится.

**Payback — два варианта:**

**Вариант A — payback ratio для Step 1 (разовый):**
```
Маржа [ГИПОТЕЗА: 40-70%]
- Worst-case 40%: payback ratio = $47.37 / ($99 × 0.40) = $47.37 / $39.60 = 1.20
  → Одна покупка Step 1 окупает CAC на 83% (1/1.20). НЕ окупается с одной продажи.
- Best-case 70%: payback ratio = $47.37 / ($99 × 0.70) = $47.37 / $69.30 = 0.68
  → Step 1 окупается с одной покупки на 147% (1/0.68). Есть запас.
```

**Вариант B — payback в месяцах для cumulative (апсейл):**

Срок дозревания апсейла оценить можно по cohort: декабрь когорта (5 мес назад) уже дала 31.8% upsell на Step 2, плюс 34.3% оттуда на Step 3. То есть полная цепочка проходит за ~3-5 месяцев. Беру **4 месяца** как среднее.

```
LTV worst (40%): $96.11 → ежемесячная отдача = $96.11 / 4 = $24.03
- Payback = $47.37 / $24.03 = 1.97 мес

LTV best (70%): $168.20 → ежемесячная отдача = $168.20 / 4 = $42.05
- Payback = $47.37 / $42.05 = 1.13 мес
```

**LTV:CAC:**

```
Worst (40%): $96.11 / $47.37 = 2.03
Best (70%): $168.20 / $47.37 = 3.55
```

**Maximum acceptable CAC** (норма 20% safety):
```
Worst (40%): $96.11 × 0.8 = $76.89
Best (70%): $168.20 × 0.8 = $134.56
```

Текущий CAC $47.37 — ниже max в обоих сценариях. Запас есть.

**Сводная таблица:**

| Метрика | Worst (маржа 40%) | Best (маржа 70%) |
|---|---|---|
| LTV (cumulative) | $96.11 | $168.20 |
| CAC | $47.37 | $47.37 |
| LTV:CAC | 2.03 | 3.55 |
| Payback (мес) | 1.97 | 1.13 |
| Max CAC | $76.89 | $134.56 |
| Запас CAC ($) | +$29.52 | +$87.19 |

**Окно оценки:** 150 дней (5 мес). Реальный LTV закрывается через 360+ дней — последние когорты ещё не дозрели до полной апсейл-цепочки.

**Вердикт:**
- **При марже 40%** — рабочая зона на грани (2.03 — между «без запаса» и «можно осторожно»). Любая просадка → минус.
- **При марже 70%** — норма (3.55), можно масштабировать осторожно (×1.3-1.5).
- Главный риск: апрельская когорта показывает Step1→Step2 всего 11.4% (vs 25% в среднем). Если это деградация воронки, а не «не дозрели» — LTV упадёт ещё.

**Без уточнения маржи давать клиенту вердикт «масштабировать» нельзя.** Это первый запрос к нему.

## Запрос 3. «iOS-корректировка для USA сегмента 30%»

(Фикс 20 — high-iOS рынки)

**USA = high-iOS рынок (~55-60% iOS share).** По методичке (раздел 5.1) — применяется множитель ×1.35-1.50.

**Что есть:** USA русскоговорящие = 30% покупателей.
- Покупателей USA на Step 1 = 380 × 0.30 = **114** (raw, по Meta Ads Manager)
- Покупателей USA на Step 2 = 95 × 0.30 = **28-29** (применяя ту же долю)
- Покупателей USA на Step 3 = 28 × 0.30 = **8-9**

**ВНИМАНИЕ — допущение:** 30% USA даны как **доля покупателей**, не как **доля spend**. Допускаю что доля spend USA тоже ~30% (то есть бюджет распределён пропорционально CAC). Это нужно подтвердить — если spend USA выше (типично для high-iOS), CAC будет другим.

**Spend USA (допущение пропорциональности):** $18 000 × 0.30 = $5 400.

**Применяю iOS-корректировку ×1.40** (среднее для USA, между 1.35 и 1.50):

| Метрика USA | Raw (Meta Ads) | iOS-corrected ×1.40 |
|---|---|---|
| Step 1 покупателей | 114 | 160 |
| CAC USA | $5 400 / 114 = $47.37 | $5 400 / 160 = **$33.75** |
| LTV worst (40%) | $96.11 | $96.11 (LTV не меняется) |
| LTV best (70%) | $168.20 | $168.20 |
| LTV:CAC worst | 2.03 | $96.11 / $33.75 = **2.85** |
| LTV:CAC best | 3.55 | $168.20 / $33.75 = **4.98** |

**Что это меняет:**
- Raw CAC показывал USA на уровне общего ($47.37). После iOS-коррекции — USA на 29% эффективнее ($33.75).
- LTV:CAC worst для USA с коррекцией = 2.85 (vs 2.03 без). Уверенная рабочая зона.
- LTV:CAC best для USA = 4.98 — масштабируемо.

**Что сделать на следующей неделе:**
1. **Проверить CRM** — выросла ли доля «direct / organic» лидов из USA за последние 90 дней. Если выросло — это и есть «потерянная» paid-атрибуция, которая вернулась через корректировку.
2. **CAPI настроен?** Если да — корректировка может быть слабее (×1.20-1.30), а не ×1.40. Проверить настройку Conversions API в Meta Events Manager.
3. **Разделить spend USA vs СНГ** в отчёте — сейчас 30% это допущение, нужны фактические цифры по гео из Ads Manager.

**Когда НЕ применять ×1.40:**
- Если у клиента работает CAPI — корректировка ниже
- Для покупок Step 2 / Step 3 — если они идут через ручную оплату на банк (не через Meta Pixel) — атрибуция Meta тут вообще ни при чём, корректировать не нужно

**Для СНГ-сегмента (70% покупателей)** iOS-коррекция НЕ применяется: РФ ~22%, КЗ ~15%, УЗ ~10% iOS share — ниже порога 50%.

## Запрос 4. «Какие бенчмарки upsell rate в INFOBIZ?»

(Фикс 4 — не выдумывать бенчмарки)

**Ответ по методичке (раздел 2.7.1):** допустимы только три варианта.

1. **Бенчмарков INFOBIZ-апсейла в скиле `reality-check-metrics` нет** (по крайней мере я их там не видел — могу проверить если нужно, но в открытой части скила бенчмарка для конкретно Step1→Step2 апсейла нет).

2. **Бенчмарков «нормы» — не существует.** Любая цифра «в INFOBIZ обычно 20-30% upsell» — это галлюцинация. Слишком много переменных: цена ступеней, разрыв между ступенями, прогревочная цепочка, оффер, аудитория, гео.

3. **Что есть честного:**
   - **Твой собственный baseline** = 25% Step1→Step2 и 29.5% Step2→Step3 за 5 мес.
   - **Внутри твоих когорт** — декабрь дал 31.8% Step1→Step2, апрель 11.4%. Это **твой собственный «коридор нормы»** — 11-32% в зависимости от месяца и зрелости когорты.
   - Твоей нормой будет улучшение от baseline: следующая когорта должна показать ≥25% Step1→Step2 при том же продукте.

**Если очень нужна точка отсчёта** — могу пометить как **[ГИПОТЕЗА: для INFOBIZ-курсов с разрывом цены × 3 (как у тебя $99→$299) типичный upsell `[ГИПОТЕЗА: 15-30%]`, для разрыва × 9 (как Step1→Step3 $99→$899) — `[ГИПОТЕЗА: 3-10%]`]**. Но это **не данные** — это диапазон для модели, не «бенчмарк для отчёта клиенту».

**Что делать с этим знанием:**
- НЕ говори клиенту «у нас upsell 25% при норме 20-30%, мы на уровне рынка» — это враньё, рынка нет.
- Говори: «Step1→Step2 25% по итогам 5 месяцев. Лучшая когорта дала 32%, худшая 11%. Улучшение возможно через [конкретные гипотезы по апсейл-цепочке]».

**Конкретные гипотезы для роста upsell** (без бенчмарков):
1. Email-серия между покупкой Step 1 и оффером Step 2 (если её сейчас нет или она слабая).
2. Сужение разрыва — промежуточный оффер $149-179 между Step 1 и Step 2, чтобы снизить психологический барьер.
3. Срок действия Step 2-оффера ограничен 7 днями после покупки Step 1 (urgency).
4. Тестовый период / гарантия возврата для Step 2.

Все эти гипотезы тестируются A/B на новой когорте, baseline — твои 25%.

## Запрос 5. «Маржа продукта неизвестна — рассчитай как ГИПОТЕЗА»

(Фикс 15 — диапазон, не точка)

**По методичке (раздел 2.7.4.1) — маржа без явной цифры от клиента ВСЕГДА диапазоном, не точкой.**

**Применимый диапазон для INFOBIZ-курсов:** `[ГИПОТЕЗА: 40-70% — уточни у клиента]`.

**Что снижает маржу INFOBIZ ниже 40%:**
- Кураторы / менторы (Step 3 mastermind с живым контактом — это вообще может быть 20-40% маржи)
- Refund > 10% (типично для холодного INFOBIZ — 5-15%)
- Эквайринг международный 4-6% (если приём через Stripe/PayPal на USD)
- Платформа (Tilda / GetCourse / Teachable) — 5-10% от продаж
- Налоги (от 6% упрощёнка до 20% НДС в зависимости от юрисдикции)

**Что поднимает маржу выше 70%:**
- Полностью автоматизированные курсы без кураторов
- Высокий LTV (когда CAC отбивается на Step 1, всё дальше — почти чистая маржа)
- Минимальные refund (брендированный продукт с лояльной аудиторией)

**Для твоего продукта (SMM-курс с апсейл-цепочкой $99→$299→$899) ставлю:**
- **Step 1 ($99 базовый):** маржа `[ГИПОТЕЗА: 60-75%]` — это автокурс, почти чистая прибыль после эквайринга и платформы.
- **Step 2 ($299 PRO):** маржа `[ГИПОТЕЗА: 50-65%]` — обычно есть какая-то поддержка / чат / обратная связь.
- **Step 3 ($899 mastermind):** маржа `[ГИПОТЕЗА: 25-45%]` — mastermind = живой контакт, время фаундера/куратора, групповые созвоны. Самая «дорогая» ступень в плане себестоимости.

**Взвешенная маржа на cumulative LTV:**

```
Веса по выручке:
- Step 1: $37 620 / $91 197 = 41.3%
- Step 2: $28 405 / $91 197 = 31.1%
- Step 3: $25 172 / $91 197 = 27.6%

Сумма весов = 41.3 + 31.1 + 27.6 = 100.0% ✓

Worst-case weighted margin:
  0.413 × 0.60 + 0.311 × 0.50 + 0.276 × 0.25
  = 0.248 + 0.156 + 0.069
  = 0.473 ≈ 47%

Best-case weighted margin:
  0.413 × 0.75 + 0.311 × 0.65 + 0.276 × 0.45
  = 0.310 + 0.202 + 0.124
  = 0.636 ≈ 64%
```

**Итог — взвешенная маржа `[ГИПОТЕЗА: 47-64% — уточни у клиента]`.**

Обратная проверка: $91 197 × 0.47 = $42 863 (worst) / $91 197 × 0.64 = $58 366 (best). Минус $18 000 spend:
- Worst прибыль: $24 863 (ROMI 138%)
- Best прибыль: $40 366 (ROMI 224%)

**Что запрашивать у клиента (приоритетный список):**

1. **Маржа Step 3 mastermind** — самая чувствительная ступень, может тянуть общую вниз на 5-10 пунктов.
2. **Refund-rate по каждой ступени** — может ли клиент дать % возвратов за 5 месяцев.
3. **Эквайринговая комиссия** — какой процессинг (Stripe/Tinkoff/Russian Post) и какой комиссионный процент.
4. **Зарплата команды кураторов / поддержки** — фиксированная или % от выручки.

Без этих 4 цифр любая «итоговая» прибыль — гипотеза с диапазоном ±27 000 USD. Это **слишком широко** для решения «масштабировать × 2».
