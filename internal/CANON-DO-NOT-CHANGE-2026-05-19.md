## 6. КЛЮЧЕВЫЕ ПРИНЦИПЫ — НЕ ОТКАТЫВАТЬ

### 6.1 Запрет сегмента Жертвы (Волна М)
Никаких «разочарованная», «уже сливала», «снова страшно», «мы понимаем тебя». Заход через инструмент / результат / число.

### 6.2 УТП в крео запрещено (Волна М)
УТП живёт в лендинге и описании продукта. В крео — суб-боль или желание + конкретное обещание + лид-магнит.

### 6.3 Запрет дисклеймеров и AI-штампов (Волна Н)
В крео не должно быть «не является медицинской консультацией», «индивидуальные результаты», «*Past performance does not guarantee future results» и т.д. — это сигнал боту/комплаенсу.

### 6.4 Англицизмы как guardrail (§13 GUARDRAILS, Волна П.16)
33 пары замен: workflow → рабочий процесс, fallback → запасной, scope → охват, etc. Индустриальные термины (CTR / ROAS / CPL / UGC / SLA) — оставлять.

### 6.5 Конкуренты через generic alias
В креативе нельзя называть конкурента по имени. «Mailchimp», «Notion», «Salesforce» → «existing email tool», «existing productivity tool», «legacy CRM».

### 6.6 Минимум 2-3 параллельных сегмента в STANDARD/PRO
Запрет «один приоритетный сегмент + остальные LATER». В STANDARD = 2-3 параллельных. В PRO = 3-5.

### 6.7 Конкретика в каждом крео
Минимум 1 измеримая величина: число / срок / чек / кейс.

### 6.8 Сильные CTA
«Пиши X в директ», «Забери сейчас». Запрещены «узнай больше», «жми», «переходи», «подробнее».

## 9. ПРИЗМА «НЕ ПЕРЕБОР ЛИ ЭТО» — мета-правило для всех будущих волн

Каждая новая правка / PRESET / категория / правило ПРОХОДИТ через 3 вопроса:

1. **Это нужно 99% таргетологов курса или 0.0001%?**
   - Если 0.0001% — НЕ добавлять в основной плагин. В крайнем случае — в отдельную ветку `experimental-extras/`.

2. **Это покрывает scope курса (CIS-except-RU + EU + USA русскоязычные релоканты)?**
   - Если нет (LATAM / APAC / Asia / Adult / Pharma Rx) — НЕ добавлять.

3. **Курс или скилы плагина ссылаются на это / зависят от этого?**
   - Если нет — это просто добавка для добавки, НЕ добавлять.

**Нарушение призмы = регрессия.** Если новый бот / агент / чат предлагает «добавим ещё одно покрытие для X региона / Y юрисдикции / Z ниши» — проверить через 3 вопроса. Если хоть один = нет, отклонить.
