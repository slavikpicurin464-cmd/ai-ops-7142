OUT-OF-SCOPE GATE
═══════════════════════════════════════════════════

Курс «AI-таргетолог» имеет фиксированный scope по гео и по профилям (10 канонических базовых). Клиенты вне scope — НЕ запускаются по конвейеру. Гейт срабатывает на этапе определения клиента и экономики (этот скил `client-profile`) ДО Reality-check.

**ГЕО ВНЕ SCOPE — отказать на онбординге:**
- Asia (Japan / Korea / Singapore / HK / China / Vietnam / Thailand / India)
- LATAM (Brazil / Mexico / Argentina / Colombia / Chile)
- Africa (Nigeria / South Africa / Egypt / Kenya)
- MENA если НЕ диаспора (UAE/SA для local Emirati / Saudi — вне scope; для русскоязычной диаспоры в UAE — IN scope)
- USA если НЕ русскоязычная / Spanish-speaking диаспора (white-American audience — вне scope)
- Australia / NZ

Что в scope:
- СНГ кроме РФ (KZ / BY / UA / KG / UZ / TJ / MD / GE / AM)
- EU полностью (включая русскоязычную диаспору в Польше / Германии / Португалии / Чехии / Балтике / Кипре)
- USA / Canada — только русскоязычные релоканты и Spanish-speaking диаспора (на этих языковых группах конвейер реально работает)

**НИШИ ВНЕ SCOPE — отказать на онбординге:**
- Pharma Rx (рецептурные препараты) — Meta запрет
- Pharma B2B chain procurement (Walgreens / CVS / Boots procurement buyers) — LinkedIn-зависимая ниша, не Meta
- Adult content (porn / эскорт / camming) — Meta запрет
- Gambling / БК / онлайн-казино — Meta запрет в большинстве гео
- Crypto trading / DeFi / NFT-спекулятивные — Meta запрет
- Unlicensed medical procedures без сертификации (БАДы без FDA / нелицензированная косметология)

Что в scope (даже если выглядит «серым»):
- Pharma OTC consumer D2C (ibuprofen / paracetamol / loratadine) — через WELLNESS_HEALTH_RESTRICTED со специальной FDA-логикой (расширение WELLNESS_HEALTH_RESTRICTED, не новый профиль)
- Adult Meta-compliant (premium lingerie / matchmaking premium ≠ porn) — через ECOM_PREMIUM_FASHION (см. подпрофиль)
- WELLNESS supplements с FDA disclaimer
- Beauty injectables с лицензией Минздрава
- B2B SaaS Enterprise — через B2B_SAAS базовый профиль + B2B_SAAS_ENTERPRISE подпрофиль уточнение (без отдельного полного пресета)

**ФОРМАТ ОТКАЗА:**

«Этот клиент {гео / ниша} — **вне scope курса AI-таргетолог**. Курс заточен под СНГ-кроме-РФ + EU + USA русскоязычные релоканты, профили {10 канонических}. Для {Asia B2B / Adult / Pharma Rx / etc} нужен специалист по этому региону / нише — там другая регуляторика, источники, форматы крео. Я не буду собирать конвейер на этот кейс, потому что: (а) не отдам качество которого ожидает middle-senior таргетолог; (б) специфика {региона / ниши} требует отдельной экспертизы которой курс не покрывает.»

Это **не отказ от работы вообще** — это разумная самооценка scope. Аналогично юристу по гражданскому праву который скажет «уголовное право — не моя специализация».

ЕСЛИ НИША НЕ ЛОЖИТСЯ НИ В ОДИН ПРОФИЛЬ (catch-all, нет force-fit)
═══════════════════════════════════════════════════

Реальная ниша иногда не лежит чётко ни в одном из 10 канонических профилей и не закрывается ни одним подпрофилем (примеры: франшизы как бизнес-возможность, антиколлекторы / списание долгов, P2P-инвестклубы без лицензии, контрафакт / реплики, SMM-накрутка / панели подписчиков, плотные гибриды коучинг+SaaS или мед+инфобиз). РАНЬШЕ такие ниши молча force-fit'ились в ближайший профиль с неверным дефолтом метрики/воронки. НЕ делай так. Алгоритм:

(а) **НЕ форсить в ближайший молча.** Назови ближайший канонический профиль И явно скажи чем ниша от него отличается («ближе всего FINTECH, но в отличие от лицензированного брокера здесь нет регулятора и продукт — антиколлектор-услуга, поэтому дефолты FINTECH по метрике/воронке не годятся»). Не подставляй дефолт родителя втихую.

(б) **Собери оси вручную** — пройди по 5 ортогональным измерениям и зафиксируй каждое явно:
   - Регистр подачи (WHITE / GREY) — обычная модерация или агрессивный DR.
   - Гео × claims/legal — легален ли claim/продукт в гео клиента (CIS-кроме-РФ / EU / USA-релоканты).
   - Канал / Special Ad Category — Meta доступна или ниша вне Meta (TG Ads / Google); и не попадает ли под SAC Housing / Employment / Financial Products & Services / Issues, Elections and Politics - но только при US/CA/EU-гео, на чистом СНГ-таргете SAC не применяется (см. блок «SPECIAL AD CATEGORY» ниже).
   - Метрика успеха — CPL / ROAS / CAC / CPFD / cost per consultation (что реально мерим).
   - Тип оффера — Hormozi-стек (двухслойная воронка) или простой прямой оффер.

(в) **Спроси ученика на развилках.** Где ось не определяется однозначно из вводных — не угадывай, задай ученику 1-2 вопроса (регистр? канал? чек/цикл?) и зафиксируй ответ. Гибрид помечай явно «основной + вторичный» и веди по основному, ограничения вторичного применяй сверху.

(г) **Для нелегальных / inauthentic — СТОП, не строй кампанию.** Если ниша = SMM-накрутка / панели подписчиков / любой inauthentic-behavior (Meta-бан по политике), нелицензированные P2P-инвестклубы / финансовая пирамида, контрафакт / реплики брендов — НЕ собирай конвейер. Объясни ученику причину одной фразой («это inauthentic behavior / unlicensed financial / counterfeit — Meta банит кабинет, и продукт вне scope курса; кампанию не строю»). Это зеркало OUT-OF-SCOPE GATE, но для ниш которые не выглядят серыми с первого взгляда.

В `00-profile.md` для unmapped-ниши пиши строкой: «Профиль: вне 10 канонических (ближайший — X), оси собраны вручную: регистр / гео-legal / канал+SAC / метрика / тип-оффера».

SPECIAL AD CATEGORY — АВТО-ФЛАГ HOUSING / EMPLOYMENT / FINANCIAL PRODUCTS & SERVICES / ISSUES, ELECTIONS AND POLITICS
═══════════════════════════════════════════════════

🛑 **СНАЧАЛА ПРОВЕРЬ ГЕО - БЕЗ ЭТОГО ВЕСЬ БЛОК НЕ ПРИМЕНЯЕТСЯ.** Ограничения Special Ad Category включаются, ТОЛЬКО если рекламодатель находится в США / Канаде / Европе ЛИБО таргетит туда. Развилка:

- **Гео клиента и гео показа - чистые KZ / СНГ (без US, CA, EU).** SAC-ограничений НЕТ вообще. Категорию в кабинете ставить не требуется, таргет НЕ режется: работай обычными узкими аудиториями, age/gender, радиусом по городу и lookalike как в любой другой нише. Не навешивай на локального казахстанского клиента широкие аудитории «потому что SAC» - это лишний рост CPL без причины.
- **В таргете или в месте рекламодателя появились US / Канада / Европа.** Тогда - всё, что ниже по блоку, обязательно.

Meta Special Ad Category (SAC) - ЧЕТЫРЕ категории, не три. При определении клиента АВТО-флагай SAC по типу ниши, независимо от базового профиля (но только после гео-проверки выше):

- **SAC = HOUSING** - вся недвижимость (новостройки, вторичка, загородка, коммерческая, аренда), не только expat-ниша REAL_ESTATE_EXPAT.
- **SAC = EMPLOYMENT** - рекрутинг, кадровые агентства, вахта, «найдём работу» / трудоустройство-инфобиз («профессия → доход / +к зарплате»), франшизы как бизнес-возможность (income/business-opportunity).
- **SAC = FINANCIAL PRODUCTS & SERVICES** (бывшая Credit, расширена 14.01.2025) - категория Credit заменена на расширенную FINANCIAL_PRODUCTS_SERVICES и покрывает не только выдачу кредита: займы, микрозаймы / МФО / PDL, кредитные и ипотечные брокеры, рефинанс, кредитные карты - И ПЛЮС банкинг, страхование, инвестиции. Практический вывод: клиент со страховкой или инвестиционными продуктами теперь тоже флагается, раньше он под категорию не попадал и проходил мимо гейта.
- **SAC = ISSUES, ELECTIONS AND POLITICS** - социально-политическая тематика, выборы, общественные вопросы. У неё обязательства ДРУГИЕ, чем у трёх верхних: она НЕ режет таргетинг, а требует верификации рекламодателя и дисклеймера «Paid for by». В ЕС политическая реклама вообще запрещена с 06.10.2025 - там это не «пройди верификацию», а «канала нет».

Что меняется при флаге HOUSING / EMPLOYMENT / FINANCIAL PRODUCTS & SERVICES (при US/CA/EU-гео): Meta режет точечный таргетинг. Конкретные параметры - возраст жёстко 18-65+ (сузить нельзя), пол только «все», минимальный радиус локации 25 км (US/CA) или 15 км (EU), нельзя ZIP-таргет и таргет по «чувствительным» интересам. **Lookalike недоступны полностью** - не «узкие нельзя, широкие можно», а инструмента нет: Special Ad Audience Meta закрыла ещё в 2022, замены не появилось, вместо него работает внутренняя Variance Reduction System. → Работать на ШИРОКИХ аудиториях + ТАРГЕТ КРЕАТИВОМ (отбор аудитории через сам месседж крео, не через настройки кабинета).

В `00-profile.md` пиши строку «Special Ad Category: HOUSING / EMPLOYMENT / FINANCIAL PRODUCTS & SERVICES / ISSUES, ELECTIONS AND POLITICS / нет (гео вне US-CA-EU)». При флаге трёх первых - пометка «таргет широкий + креатив-таргет, age/gender/ZIP сужать нельзя, lookalike недоступны». При флаге четвёртой - пометка «верификация рекламодателя + дисклеймер Paid for by; в ЕС канал закрыт». SAC ортогонален профилю и подпрофилю - ставится дополнительным полем.

АВТО-ПРИСВОЕНИЕ ПОДПРОФИЛЯ — ДИЗАМБИГУАТОР
═══════════════════════════════════════════════════

Подпрофиль НЕ присваивается «по умолчанию родителя». РАНЬШЕ на развилках (где базовый профиль раздваивается на подпрофили) суффикс не ставился явно — и downstream (Reality-check метрика, профильные акценты на этапах подходов и крео, формат крео) брал дефолт родителя, что давало неверную метрику/воронку. Где ниша попадает на развилку — ЯВНО присвой подпрофиль через 2-3 вопроса-дизамбигуатора:

- **B2B_SAAS → _SMB vs _ENTERPRISE.** Вопросы: чек ($19-299/seat или $300+/seat) / цикл (7-30 дней self-serve или 60-90+ дней с buying committee) / канал продажи (self-serve trial или sales-led demo). Триггер чека $300+/seat → _ENTERPRISE; иначе _SMB. Mutually-exclusive.
- **Психология → SOFT_EXPERT vs CRISIS_EXPERT.** Вопросы: состояние клиента (плановая работа над собой или острый кризис — развод/утрата/банкротство/уголовка) / чек и срочность. Кризис + конкретика срочности → CRISIS_EXPERT (бережность ломает работу); плановая → SOFT_EXPERT.
- **Коучинг → INFOBIZ vs HIGH_TICKET vs EXECUTIVE_COACHING.** Вопросы: чек (до 1000 / 1000+ за сделку) / есть ли обязательный созвон-консультация (авто-воронка → INFOBIZ; созвон + чек 1000+ → HIGH_TICKET) / аудитория (топы/собственники → EXECUTIVE_COACHING, операционный регистр).
- **Мебель / стройматериалы → ECOM vs B2B vs HIGH_TICKET_LOCAL_SERVICE.** Вопросы: кто покупает (физлицо / бизнес-опт) / чек и цикл / гео-привязка и формат (каталог-D2C → ECOM; опт → B2B; на заказ под объект, чек 1500+, гео → HIGH_TICKET_LOCAL_SERVICE).

Результат пиши в `00-profile.md` строкой «Профиль: X / подпрофиль: Y» (а если подпрофиль реально не применим — «подпрофиль: не выбран», но это осознанное решение, не пропуск). Без явного присвоения downstream берёт дефолт родителя — это баг, не норма.

Этот скил говорит про артефакты по смыслу — профиль клиента, сырьё ресерча, сегментация с Картой смыслов, офферы, крео, аналитика. В пакете это файлы в папке клиента: `00-profile.md`, `01-research-raw.md`, `02-segments-map.md`, `03-offers.md`, `04-creatives.md`, `05-analytics.md`. Если работаешь без курса — используй любую таблицу с теми же столбцами.

# Client Profile

Ты определяешь клиента за один проход - сразу профиль ниши и бюджетный режим. Это вход в этап определения клиента и экономики. Без этих двух решений конвейер работает как generic и теряет точность под конкретный тип бизнеса.

## Когда использовать

Срабатывает на этапе определения клиента и экономики в момент когда ученик впервые описал клиента - продукт, канал продаж, чек, бюджет в месяц. Также подгружается если бюджет или продукт изменились в середине цикла и нужно пересчитать пару (профиль + режим) со следующего этапа производства крео.

Триггер-фразы ученика.
- «определи клиента»
- «профиль клиента»
- «определи режим»
- «какой профиль ниши»
- «потянет ли клиент полный конвейер»
- «у клиента бюджет X / онлайн-курс / стоматология / магазин / SaaS / премиум»

НЕ подгружай если:
- Профиль и режим уже зафиксированы в профиле клиента (`00-profile.md`) и вводные не менялись.
- Ученик задал общий вопрос на знание («чем отличается ECOM от INFOBIZ», «что такое LITE режим») без своего клиента - это вопрос к `ru-marketer` или к Части 4 (бюджетные режимы) и Части 3 (профили ниш) KONVEYER-LOGIKA.md напрямую.
- Бюджет указан в неявных терминах («небольшой», «обычный», «как у всех») - запрашиваем конкретную цифру в USD до классификации.

## Что делает

Шаг 1. Запрашивает у ученика короткое описание клиента одним блоком.

- Что продают (продукт).
- Канал продаж - онлайн / локально / гибрид.
- Средний чек в USD.
- Цикл сделки от первого касания до оплаты в днях (если известно).
- Кто покупает - физлицо / B2B-компания.
- Месячный бюджет на трафик в USD.

Если бюджет указан в местной валюте - курс по памяти НЕ применяй. Спроси у ученика курс на сегодня («1 USD = ? тенге / рублей / гривен») или попроси цифру сразу в USD. Использованный курс пиши в артефакт строкой: «бюджет X USD при курсе Y на дату Z». Годовой/квартальный бюджет переводи в месячный делением.

Для недвижимости (REAL_ESTATE_EXPAT и любая другая) дополнительно обязательны поля - банки-партнёры и их ипотечные программы, минимальный первый взнос, срок сдачи объекта, формат целевого действия (заявка / визит в офис / бронь). Без этих полей этап определения клиента и экономики не закрывается - таргет на недвижку без ипотечной матрицы и без понятного целевого действия работает вслепую.

Шаг 2. Параллельно классифицирует ПРОФИЛЬ НИШИ по 10 каноническим типам.

Канон 10 профилей:
- INFOBIZ / ИНФОБИЗ - инфопродукты, курсы, марафоны, личное сопровождение
- LOCAL_SERVICE / ЛОКАЛЬНЫЙ-СЕРВИС - локальный сервис с привязкой к гео-точке (салоны красоты, фитнес-клубы, ремонт, стоматология, медицина общая)
- ECOM / ИНТЕРНЕТ-МАГАЗИН - интернет-магазины с собственной витриной (D2C, бренды)
- B2B_SAAS / B2B-СЕРВИС - B2B сервисы, SaaS, корпоративные продукты
- HIGH_TICKET / ПРЕМИУМ - премиум-продукты от 1000 USD за единицу (включает executive-коучинг как подпрофиль)
- CRISIS_EXPERT - кризисные ниши (юр-кризис: банкротство, развод, уголовка; острые психо-состояния; ритуалы)
- REAL_ESTATE_EXPAT - недвижимость для expat-аудитории (Golden Visa, D7, Beckham law, Cyprus PR)
- WELLNESS_HEALTH_RESTRICTED - wellness под US FTC / Canada Health Canada / EU regulators (БАДы, hormonal coaching, supplements)
- KIDS_PARENTS - детские курсы / развивайки / детский спорт / семейные продукты с COPPA + GDPR-K + state student-data privacy.
- ECOM_IMPULSE - WOW-товары через Reels / TikTok-style с retention=0 (упрощённая Hormozi воронка). AOV $15-100, импульсная покупка.

Подпрофили — уточнение базового профиля вторым полем (формат «BASE + специфика»). Полный список 15+ подпрофилей и GREY_NICHE надстройка — см. блок «ПРОФИЛИ — КАНОН KONVEYER» в начале файла. Базовый профиль обязателен, подпрофиль — если применим.

Разбор каждого профиля ниже.

ИНФОБИЗ - онлайн-курсы, школы, наставничество, инфопродукты, экспертка, консалтинг через марафоны. Чек 50-1000 USD. Цикл 7-30 дней.

ЛОКАЛЬНЫЙ-СЕРВИС - стоматология, бьюти, ремонт техники/квартир, юристы локально, фитнес-студии, барбершопы, автосервисы. Привязка к гео-радиусу. Чек 30-500 USD. Цикл 1-7 дней.

ИНТЕРНЕТ-МАГАЗИН - одежда, косметика, гаджеты, FMCG, товарка с каталогом, маркетплейс-селлеры с собственным сайтом или D2C. Импульсные покупки. Чек 10-200 USD. Цикл 1-3 дня.

ECOM_MARKETPLACE_SELLER - подтип ECOM для селлеров на маркетплейсах (Kaspi, Wildberries-аналоги в СНГ). Отличия от стандартного ECOM:
- Pixel и CAPI не на собственном сайте а на странице товара маркетплейса (или нет вообще)
- Оптимизация через события самого маркетплейса (Kaspi Ads)
- Цикл сделки короче (нет регистрации, корзина и checkout на платформе)
- Конкуренция выше потому что покупатель видит цены конкурентов рядом на одной странице
- Атрибуция сложнее - реклама в Meta а покупка в Kaspi, без UTM-цепочки трекать сложно

B2B-СЕРВИС / B2B_SAAS - SaaS, B2B-услуги, агентства, корпоративный консалтинг, IT-аутсорс, оптовая торговля. Платит компания. Цикл 30-90 дней с прогревом. Обязательный атрибут профиля - цепочка ЛПР из трёх звеньев. Инициатор (HR / operations / руководитель отдела) приносит идею. Валидатор (операционный директор / IT-директор / руководитель проекта) проверяет соответствие процессам. Подписант (CFO / CEO / собственник) даёт деньги. Если в воронке учтён только один из трёх - сделка стоит на полпути. Воронка демо-первая, не лид-магнит - холодный B2B-аккаунт не качает PDF, он бронирует созвон с продактом. Лид-магнит как первичка работает только для SMB-сегмента с чеком до 200 USD/мес.

ПРЕМИУМ - премиум-наставничество от 1000 USD/чек, high-end коучинг для топов, luxury-услуги, медтуризм, светский премиум-туризм. Цикл 30-180 дней.

МЯГКИЙ-ЭКСПЕРТ (SOFT_EXPERT) - психологи, КПТ-терапевты, нутрициологи, диетологи, юристы-консультанты, коучи по здоровью, медицинская косметология, реабилитация, физиотерапия. По чеку часто пересекается с ИНФОБИЗ (60-400 USD), но этика и регуляторика жёстче. Цикл 3-21 день, решение часто отложенное из-за деликатности темы.

REAL_ESTATE - новостройки, вторичка, загородка, коммерческая недвижимость. Чек 30-300к USD. Цикл 90-365 дней. Обязательны офис продаж и менеджер - таргет приводит лида, закрывает офлайн. Ипотека входит в оффер как часть продукта, не как доп. условие.

RELIGIOUS_TRAVEL - религиозный туризм: умра, хадж, паломничество. Чек средний-высокий. Цикл 3-9 месяцев. Решение семейное, многопоколенческое - бабушка/родители/дети решают вместе. Тема деликатная, требует уважительного тона без давления и срочности.

FINTECH / INVESTMENTS - лицензированные финансовые продукты: брокеры, банки, инвестприложения, страхование, P2P-кредитование, кэшбек-карты. Не путать с криптотрейдингом и нелицензированными «инвестклубами» - те идут в серую зону и в плагине не поддерживаются. Чек первого пополнения 50-5000+ USD. Цикл 7-30 дней до первого пополнения, потом retention и удержание AUM. Регуляторика жёстче Meta - лицензия регулятора финансового рынка юрисдикции (КЗ: АРРФР; РФ: ЦБ; РБ: НБРБ; Украина: НКЦБФР), закон о рекламе юрисдикции в части финуслуг (КЗ: Закон РК «О рекламе»; РФ: ФЗ-38 ст.28; РБ: Закон РБ «О рекламе»; Украина: Закон «Про рекламу»), обязательный disclaimer ВНУТРИ креатива (не в описании рядом - именно в кадре), номер лицензии, предупреждение о рисках. Маркировка рекламы (ОРД/erid) - РФ-специфика, опция; для КЗ/РБ/Украины не требуется на уровне Meta, проверь локальный закон. Воронка двухступенчатая - регистрация → KYC → первое пополнение. CPL до регистрации и CPL до пополнения - две разные метрики, считать отдельно.

ECOM_IMPULSE - импульсный e-com через Reels / WOW-товары / TikTok-style на FB/Insta. Цикл 5-30 минут от показа до оплаты. Чек $15-100, retention=0 (одна покупка, без повторов). Метрики - CPP (cost per purchase) и ROAS, не CPL. Бренда нет, есть товар - продаём один SKU в одном крео, не каталог. Learning phase 1-2 дня (короче чем у обычного e-com потому что цикл короче). Отделяется от ИНТЕРНЕТ-МАГАЗИН по двум маркерам - нет D2C-каталога и сайта, нет повторных покупок. Если у клиента есть бренд, каталог, повторки - это ИНТЕРНЕТ-МАГАЗИН с обычными метриками.

MEDICAL_HEAVY (подпрофиль LOCAL_SERVICE HIGH_TICKET (медицина), не отдельный профиль) - тяжёлая медицина: ЭКО, онкология, пластическая хирургия с инвазивкой, кардиохирургия, репродукция. Чек одной программы 2000+ USD, LTV пары через 2-3 попытки + сопутствующие процедуры 10-25к USD. Цикл 1-6 месяцев от первого касания до программы. Лицо клиники - врач, не пациентка (закон об охране здоровья юрисдикции в зависимости от страны - для РФ это 323-ФЗ ст.24, РФ-специфика; в КЗ/РБ/Украине свой профильный закон + Meta Health Policies). До/после, истории пациентов, «вылечила N человек» - запрет. Угол работает - «прозрачность»: статистика по возрастным группам, протоколы, язык врача без эмоциональной накачки. Регуляторика - закон о рекламе юрисдикции в части медуслуг (КЗ: Закон РК «О рекламе»; РФ: ФЗ-38 ст.24; РБ: Закон РБ «О рекламе»; Украина: Закон «Про рекламу»), лицензия профильного министерства здравоохранения юрисдикции (КЗ: МЗ РК; РФ: Минздрав РФ; РБ: МЗ РБ; Украина: МОЗ), санитарные нормы юрисдикции. Отделяется от МЯГКИЙ-ЭКСПЕРТ по чеку и инвазивности - психолог и нутрициолог это SOFT_EXPERT, репродуктолог и пластический хирург это MEDICAL_HEAVY.

SUBSCRIPTION_BOX / RECURRING - подписочные сервисы: бьюти-боксы, мил-киты, кофе по подписке, корм для животных, любые сервисы с recurring revenue и tripwire-входом. Главная метрика - LTV/CAC ratio на горизонте 6-12 месяцев. Маржа на одну коробку 25-40%. Ежемесячный churn 30-50% после M1, к M6 удерживается 25-40% когорты. Воронка - tripwire (первая коробка по низкой цене 5-15 USD) → автосписание → удержание. По чеку первой покупки экономика всегда «не складывается» - считать только по LTV_6мес.

KIDS_PARENTS - детские продукты: онлайн-школы для детей (английский, программирование, математика), развивашки, детский спорт и медицина, лагеря, развивающие игрушки и игры. ЛПР = родитель, пользователь = ребёнок - две разные мотивации. Родитель покупает «безопасность будущего» и «инвестицию в развитие», ребёнок хочет «прикольно и не скучно». Сезонность учебного года жёсткая - август-сентябрь пик, январь-март вторичный пик (январь «начать с чистого листа», февраль-март «доделать год»), май-июль провал 3-5x относительно сентября. 4-слойная воронка - заявка родителя → пробный состоялся → ребёнок захотел продолжать → родитель оплатил. Каждый из 4 переходов - отдельный CR. Категория Meta «Семья и дети» строже базовой - запрет сравнений детей между собой, запрет таргетинга по детским интересам напрямую, запрет «твой ребёнок отстаёт».

CRISIS_EXPERT (базовый канонический профиль; SOFT_EXPERT - его некризисный подпрофиль) - юридические услуги в кризисе (банкротство физлица по законодательству юрисдикции, развод с разделом, уголовная защита, налоговые споры), ритуальные услуги, врачи острых состояний (наркологи, кризисные психологи, реаниматологи частной практики). Чек 800-3500 USD, цикл 7-60 дней. Главное отличие от обычного SOFT_EXPERT - клиент в катастрофе, бережность ломает работу. Когда у человека уголовное дело, банкротство или умер близкий - он не хочет «мягкого присутствия», он ждёт экспертности и конкретики. Переформулировки бережного режима:
- Страх не убирать - переформулировать в «риск-процедуру» (объективные последствия по закону юрисдикции, не пугание: «по статье уголовного кодекса юрисдикции срок до N лет», «при пропуске срока имущество не возвращается»). Конкретный номер статьи подставляется под юрисдикцию клиента.
- Срочность не убирать - переформулировать в «процессуальный срок» (объективный дедлайн по процессуальным кодексам юрисдикции, не маркетинговый «осталось 3 места»).
- Статус заменить на «экспертность» (стаж, статистика выигранных дел, номер удостоверения, специализация).

Два рабочих регистра подачи. Холодный экспертный - на «вы», со ссылками на закон и статью кодекса юрисдикции, цифры и сроки. Тёплый человеческий - на «ты», эмпатия + сразу конкретика («да, это страшно. По закону у тебя есть 30 дней, давай разберём по шагам»). Бережность из обычного SOFT_EXPERT (медленный темп, валидация чувств, «дай себе время») к CRISIS_EXPERT НЕ применять - клиент горит, ему нужно действие.

Адвокатская монополия — РФ-специфика. В КЗ/РБ/Украине свои правила, проверь по своей юрисдикции до запуска кампании на юр-услуги.

ДОПОЛНИТЕЛЬНЫЕ ПОДПРОФИЛИ ДЛЯ EU/USA РЫНКОВ.

B2B_PROFESSIONAL_SERVICES - подтип B2B_SAAS для услуг (law firms, consulting boutiques, wealth management, accounting). Отличия:
- Канал в курсе = Meta (FB+IG): demand-gen через thought-leadership + retargeting decision-chain(курс ТОЛЬКО Meta/IG). В реальности ниша сильно на LinkedIn, но LinkedIn/ABM вне scope курса — только по явному запросу ученика
- Цикл сделки 30-180 дней с 3-link decision chain (Initiator/Validator/Signatory)
- LTV огромный (€10K-1M+ за case), CAC потолок выше типичного B2B SaaS
- Контент - thought leadership (whitepapers, webinars, invitation-only roundtables), не aggressive CTA
- Compliance - запрет comparative ads (Bar rules в Bel/UK), FINMA для wealth (CH), FCA для UK finance
- Trust signals - partner credentials, big clients, regulatory licenses, ex-magic-circle DNA

REAL_ESTATE_EXPAT - базовый канонический профиль для недвижимости под expat-niche (Portugal Golden Visa/D7, Spain Beckham law, Italy flat-tax, Cyprus permanent residence, etc). Отличия:
- Target - не местные а англоязычные buyers (US retirees, UK Brexit refugees, Brazilian wealth migration, digital nomads pre-residency)
- Канал в курсе = Meta (FB+IG); ⚠️ Meta Special Ad Category Housing блокирует точечный таргет (age/gender/ZIP) → широкие аудитории + таргет креативом. LinkedIn/Reddit/expat-groups вне scope курса — только по явному запросу ученика
- Цикл 90-180 дней, multiple touchpoints
- LTV миллионы EUR
- Compliance - Meta Housing Special Category (нельзя age/gender/ZIP), GDPR, locally — AMI license, FATCA для US buyers
- Главная метрика - cost per qualified discovery call (не CPL на лиде)
- Visa rules часто меняются (Portugal Golden Visa 2023 убрал direct real estate path)

MEDICAL_HEAVY на рынках EU/USA (UK dental ASA+GDC, US doctors HIPAA, Germany Heilmittelwerbegesetz, French Code de la santé publique). Это тот же подпрофиль MEDICAL_HEAVY с поправкой на западную регуляторику, не отдельный профиль (старое имя HEALTHCARE_COMPLIANCE_HEAVY = устаревший синоним MEDICAL_HEAVY). Отличия:
- Запрет guaranteed results, before/after с disclaimers только
- Comparative claims под запретом
- Testimonials с ограничениями (UK ASA - real patients, full consent, не до/после процедур)
- Цикл 30-90 дней (consultation → treatment plan → payment)
- Канал в курсе = Meta (FB+IG) для awareness/demand-gen. Google Search для high-intent дешевле, но search вне scope курса — только по явному запросу ученика
- Compliance - не «избавим» / «вылечим» / «гарантируем», только «may help» / «associated with»
- Trust - GDC/medical license number в крео, real practitioners only (no actors for results claims)

WELLNESS_HEALTH_RESTRICTED - подтип INFOBIZ / SOFT_EXPERT для wellness с health claims под US FTC / Canada Health Canada / EU regulators. Отличия:
- НЕТ medical claims (cure / treat / heal / fix / reverse) - блок Meta + штрафы regulator
- Можно «may support», «associated with», «in some users», testimonials с disclaimers
- Канал = Meta (Facebook + Instagram Reels). US wellness в Meta работает при соблюдении compliance rules ниже
- Most-aware audience часто (burned by previous coaches/diets), нужен validation-first tone
- Trust signals - certifications (NTP, FDN, IFM), licensed ND (Canada), partnered with MDs
- HIPAA-adjacency в US - intake forms требуют HIPAA-compliant storage
- Health Canada блокирует ~40% типовых hooks конкурентов

Маркер. Если эксперт работает в health / mental / medical / legal и его рекламные обещания регулируются профессиональной этикой ниши - это МЯГКИЙ-ЭКСПЕРТ, не ИНФОБИЗ. Сваливание в ИНФОБИЗ даёт инструкции «соцдоказ через истории клиентов + срочность» что прямо нарушает этику.

Что меняется в работе по этому профилю.
- На этапе ресерча аудитории - транскрипты консультаций (с анонимизацией) - приоритетный источник tone of voice.
- На этапе сегментации - сегментация по триггеру и стадии принятия проблемы, не по демографии. Аудитория одного клиента сразу на 2-3 стадиях awareness.
- На этапе подходов / матрицы 4 углов - запрещённые углы: «срочность» на тревожной ЦА, «страх» переформулировать в «прояснение последствий», обесценивание текущего состояния клиента, гарантии результата, медобещания.
- На этапе производства крео - UGC реальных клиентов невозможен без процедуры письменных согласий. Формат - экспертный talking-head или атмосферный без CTA в кадре.
- До/после в wellness и похудении Meta НЕ запрещает блокетно. Отдельной политики «Personal Health and Appearance» больше нет, всё сведено в **Health and Wellness** (ред. 22.07.2026), и запрета на кадры до/после там нет. Явно разрешено: косметические процедуры с кадрами до/после; продукты для похудения - можно показывать человека, использующего продукт, при условии что ясно указан срок, за который получен заметный результат.
- Что реально запрещено в этой политике: заявления о неполноценности внешности (стыд за тело, «ты не в форме - с тобой что-то не так»); крупный план с защипыванием жира и подобной фиксацией на «проблемной» зоне; обещание результата «только от гаджета / прибора» без остального; кликбейт со сроком результата без дисклеймера. Таргет 18+ обязателен - без него крео отлетает независимо от содержания.
- Отдельно: на серых офферах до/после остаётся зоной высокого риска ОТКЛОНЕНИЯ на модерации (практика ревью жёстче текста политики) - но это риск отклонения крео, а не запрет политикой. Планируй запасной вариант крео без до/после, не выкидывай формат целиком.
- На этапе аналитики недели - метрика Lead, не Purchase. Атрибуция мягче из-за отложенного решения.

Шаг 3. Параллельно классифицирует БЮДЖЕТНЫЙ РЕЖИМ по 3 границам (канон LITE / STANDARD / PRO — см. начало файла).

- **LITE** — до 500 USD/мес. Самозанятые, микро-бизнесы, локальные мастера.
- **STANDARD** — 500-3000 USD/мес. Малый бизнес, фрилансеры с подросшим чеком, локальные сети 2-5 точек.
- **PRO** — 3000+ USD/мес. Средний и крупный бизнес, инфопродукты с потоком 30+ заявок/день, e-commerce с каталогом.

Если бюджет на границе диапазона (480-520 USD или 2500-3500 USD) — действуй по правилам «ПОГРАНИЧНЫЕ ЗОНЫ» в начале файла: спрашивай ученика, не назначай автоматом. Помечай возможность перехода в следующий режим после первой итерации с подтверждённым ROAS.

Шаг 4. Проверяет совместимость пары (профиль + режим).

Комбинации со СТОП-разговором (это не отказ от работы). Механика одна на все три: показываешь ученику расчёт, даёшь 3 варианта решения, и дальше идёшь только по явному «да» ученика — с записанным в `00-profile.md` риском («идём на свой страх, окно оценки удлинённое, вердикт по промежуточной метрике»). Совпадает со сценарием B+ в `reality-check-metrics`: не блокируем, а уведомляем о риске и двигаемся по согласию.

- LITE + B2B_SAAS - на 400 USD/мес квал-лид B2B стоит 30-80 USD, цикл 30-90 дней. Получишь 0-2 лида/мес при сделках на квартал. Проект физически не запускается.
- LITE + HIGH_TICKET - на маленьком бюджете цикл 30-180 дней не закроется, ROI не виден.
- LITE + MEDICAL_HEAVY - на 500 USD/мес чек программы 5000+ USD не запустится. CPL_лид 40-100 USD даёт 5-12 лидов/мес, итоговая воронка 2-7% - это 0-1 пациент в окно оценки 8-12 недель. Экономика не видна, выводы по тесту нельзя сделать.

Предупреждение (без СТОП-разговора, работаем дальше сразу):
- STANDARD + HIGH_TICKET - возможно но потребует более длинного окна оценки и заранее согласованного с клиентом «месяца сбора данных».
- STANDARD + B2B_SAAS - возможно при чеке до 200 USD/мес и SMB-сегменте с циклом до 14 дней. На enterprise B2B с циклом 60-90 дней STANDARD-бюджет даёт 8-15 квал-лидов/мес - окно оценки 10-12 недель, ROI виден только на квартальном горизонте.
- STANDARD + MEDICAL_HEAVY - окно оценки 8-12 недель. Поток лидов 15-30/мес, итоговая воронка 2-7% - это 1-3 программы в окно. Ранний вердикт по сырому CPL и стоимости консультации, не по выручке.
- STANDARD + SOFT_EXPERT / CRISIS_EXPERT при бюджете < 1500 USD/мес - математика сходится, но learning phase набирается медленно. Окно оценки 8-12 недель вместо 4-6. Проговорить с клиентом до старта, прогнать через `reality-check-metrics` (там для SOFT_EXPERT задан минимальный жизнеспособный бюджет 1500-2000 USD/мес и сценарий B+ ниже этой планки).
- STANDARD + SUBSCRIPTION_BOX - совместимо, но окно оценки 6-8 мес для LTV/CAC. На горизонте до 3 мес ROAS будет ниже 1 - это норма для recurring модели, не сигнал KILL. Согласовать с клиентом до запуска что первые 2-3 месяца оцениваем по CAC к LTV_6мес прогнозному, не по выручке месяца.
- PRO + REAL_ESTATE_EXPAT - совместимо, но бюджет надо проверять отдельно через `reality-check-metrics`. При CPL 50-150 USD на сырого лида даже большой бюджет даёт ограниченный поток - лидов может не хватить на план продаж застройщика. Считаем сколько визитов в офис реально вытягивает бюджет до старта.
- PRO + FINTECH - совместимо, но проверять предельный CAC через `reality-check-metrics`. При чеке первого пополнения 50-200 USD предельный CAC мал, а реальный CPL до пополнения 20-40 USD - экономика «в плюс» только с учётом retention и AUM. Запуск без LTV-модели даёт ложно-отрицательный сценарий C на первом цикле.

Если комбинация из списка СТОП-разговора - выдаёт расчёт и три варианта решения и останавливается. Дальше идёт либо после пересмотра вводных, либо по явному «да» ученика с записанным в `00-profile.md` риском. Молча продолжать нельзя, но и отказывать в работе за ученика - тоже.

Шаг 5. Выдаёт пару (профиль + режим) с настройками работы по конвейеру.

Под профиль накладываются правки на этапы:
- На этапе ресерча аудитории - источники цитат под нишу.
- На этапе сегментации - принципы сегментации (Schwartz обязателен / необязателен / адаптация).
- На этапе подходов / матрицы 4 углов - какие подходы 4 из 8 в приоритете.
- На этапе производства крео - формат крео (UGC / статика / cinematic / демо / до-после) с пропорциями.
- На этапе аналитики недели - главная метрика (CPL / ROAS / CPQL / cost per booked appointment).

Правки под ИНФОБИЗ:
- **Специфика Meta-модерации для ИНФОБИЗ** (особенно курсы с темой заработка / новой профессии / удалёнки):

  Meta режет прямые денежные обещания: «зарабатывай 100к», «гарантированный доход», «брось работу мечты», «удалёнка с 1500 USD». Используй обходные формулировки из таблицы «нельзя → можно для education» в `offer-generator` (например: «гарантированное трудоустройство» → «помогаем с портфолио и стажировкой»; «зарабатывай от 100к» → «средняя зарплата junior-специалиста на job-агрегаторе юрисдикции (hh.kz / hh.by / rabota.ua / hh.ru) — X»). Свои формулировки не выдумывай: если нужной строки в таблице нет, иди в `meta-policy-checker`, а не сочиняй денежное обещание сам.

  В крео избегай прямого таргета «Безработные» — Meta понижает охват таких сегментов. Тарify через интересы профессии (Figma, Tilda, профильные паблики), демографию по возрасту и доходу — не по статусу занятости.

Правки под REAL_ESTATE_EXPAT (и любую недвижимость под SAC=HOUSING):
- На этапе аналитики недели - главная метрика cost per booked appointment (визит в офис продаж), CPL вспомогательная. Сырой лид сам по себе ничего не значит - считаем стоимость доведённого до офиса.
- На этапе сегментации - сегментация по мотиву покупки (инвестиция / для себя / переезд из региона / расширение для семьи), не по демографии. Мотив определяет оффер и крео сильнее, чем возраст и доход.
- На этапе производства крео - рендеры, облёты дронами, планировки. UGC жильцов невозможен - объект не сдан, жить там пока некому.
- Окно оценки - минимум 6-8 недель «фазы сбора данных». Сделки в окно атрибуции не попадают, ранний вердикт по ROAS невозможен.

Правки под FINTECH / INVESTMENTS:
- На этапе ресерча аудитории - источники цитат: отзывы на профильных финансовых порталах юрисдикции (для КЗ - Halyk Finance / forbes.kz; для РБ - Infobank.by; для Украины - Minfin.com.ua; для РФ - Banki.ru, опция), Trustpilot, App Store / Google Play по приложению, профильные telegram-каналы по теме (инвестиции, личные финансы), Reddit r/personalfinance региональный.
- На этапе сегментации - сегментация по уровню финграмотности и цели (новичок с зарплатой 1000+ / опытный с портфелем / искатель пассивного дохода / валютный хедж). Демография вторична, финповедение первично.
- На этапе подходов / матрицы 4 углов - подходы СОЦДОКАЗ (через цифры и регулятора финансового рынка юрисдикции, не «истории заработавших») и ВЫГОДА (через ставку, кешбек, налоговый вычет если применимо по юрисдикции). Подход «срочность» через объективные дедлайны (закрытие инвестсчёта с налоговыми льготами - в РФ это ИИС, в КЗ свои инструменты, проверяй по юрисдикции; конец налогового периода). Запрет на гарантии доходности, обещание прибыли, истории «заработал X за месяц».
- На этапе производства крео - формат cinematic + анимация / motion-графика с цифрами. UGC «обычных людей которые заработали» - запрет регулятором финансового рынка юрисдикции. Disclaimer ВНУТРИ кадра минимум 4 сек, шрифт читаемый, не серый по серому.
- На этапе аналитики недели - главная метрика CPL до первого пополнения (CPFD - cost per first deposit), не CPL до регистрации. Регистрации без KYC и пополнения денег не приносят. Метрика-светофор - доля регистраций дошедших до KYC (норма 30-50%).

Правки под ECOM_IMPULSE:
- На этапе ресерча аудитории - источники: комментарии под рилсами конкурентов в нише товара, отзывы маркетплейсов по аналогам, TikTok-комменты по похожим товарам. Не лезть в Telegram-чаты - там не сидит целевая.
- На этапе сегментации - 1-2 сегмента максимум. Импульсный e-com не любит дробной сегментации - один товар, одна целевая боль, один оффер.
- На этапе подходов / матрицы 4 углов - подходы ВЫГОДА (скидка / комплект) и ЭМОЦИЯ (вау-эффект демо). Соцдоказ через быстрые отзывы и счётчик заказов.
- На этапе производства крео - 100% видео-демо товара 9-15 секунд в TikTok-style. Static не работает - импульс ловится движением. Hook первые 1.5 сек обязательно показ товара в работе.
- На этапе аналитики недели - главная метрика CPP (cost per purchase) и ROAS. CPL не считаем - воронки в один шаг, лид = покупатель в течение 30 минут. Reality-check на день 2-3, не на день 5-7 (learning phase короче).

Правки под MEDICAL_HEAVY:
- На этапе ресерча аудитории - источники: транскрипты консультаций (с письменным согласием и анонимизацией), профильные сообщества пациентов (онко-форумы, ЭКО-чаты), отзывы на профильных порталах оценки врачей юрисдикции (для КЗ - DocDoc.kz / emed.kz; для РБ - DocDoc.by; для Украины - DocLine / Likarni.com; для РФ - ПроДокторов / Docdoc, опция). Язык цитировать врача, не пациентки.
- На этапе сегментации - сегментация по стадии принятия диагноза (отрицание / поиск второго мнения / выбор клиники / готов к программе) и по возрастной группе (для ЭКО критично - протоколы разные). Не по демографии.
- На этапе подходов / матрицы 4 углов - подходы СОЦДОКАЗ (через статистику клиники, не истории пациентов) и ЭКСПЕРТНОСТЬ (через врача в кадре, сертификаты, протоколы). Запрет на гарантии результата, «100% беременность», «победили рак», до/после, истории пациенток.
- На этапе производства крео - врач talking-head в халате на фоне клиники, без эмоциональных трейлеров. Cinematic интерьеров клиники как фоновый материал. UGC пациентов - запрет.
- На этапе аналитики недели - главная метрика cost per consultation (стоимость состоявшейся консультации), не CPL и не CPP. Промежуточная метрика - доля лидов дошедших до консультации (30-50%). Окно атрибуции 28-day click + CRM-сверка обязательны - в Meta-окно ничего не доезжает.

Правки под SUBSCRIPTION_BOX:
- На этапе ресерча аудитории - источники: отзывы маркетплейсов по аналогичным боксам, профильные сообщества (бьюти-чаты, мил-кит сабреддиты), социалки конкурентов (Insta, TikTok).
- На этапе сегментации - сегментация по поводу подписки (себе / в подарок / для семьи) и по жизненной ситуации (мама в декрете / занятый офисник / новосёл). Каждый сегмент даёт разный churn.
- На этапе подходов / матрицы 4 углов - подходы ВЫГОДА (tripwire по сниженной цене первой коробки) и ЭМОЦИЯ (распаковка как ритуал). Срочность только на сезонных боксах (новогодний, Valentine, 8 марта).
- На этапе производства крео - UGC распаковок 60% + cinematic-съёмка коробки 30% + статика-каталог содержимого 10%. Распаковка - главный формат, ловит на «что внутри».
- На этапе аналитики недели - главные метрики CAC и LTV_6мес. ROAS на горизонте 1 месяца всегда <1 для подписки, это норма. Окно оценки 6-8 месяцев, на горизонте 1-2 месяцев оцениваем только CAC и retention M1→M2.

Правки под KIDS_PARENTS:
- На этапе ресерча аудитории - источники: родительские telegram-чаты по школе/району, отзывы на профильных порталах оценки врачей юрисдикции (для КЗ - DocDoc.kz / emed.kz; для РБ - DocDoc.by; для Украины - DocLine; для РФ - ПроДокторов / Отзовик, опция) по детским врачам, родительские форумы юрисдикции (для РФ - НеНудно, Babyblog, опция; для КЗ/РБ/Украины - локальные родительские сообщества и Instagram-аккаунты), школьные родительские чаты конкурентов (через своих).
- На этапе сегментации - две воронки целей одновременно. Для родителя - сегментация по мотиву («билингвизм / поступление в школу / занять ребёнка / развить талант / догнать программу»). Для ребёнка - сегментация по интересу («чтобы интересно как игра / чтобы с друзьями / чтобы не как в школе»). Оффер и крео делать отдельно под родителя в Reels Instagram и отдельно под ребёнка в TikTok / на лендинге.
- На этапе подходов / матрицы 4 углов - подходы СОЦДОКАЗ (через отзывы родителей и работ детей) и ЭМОЦИЯ (через радость ребёнка). Запрет на сравнение детей («твой ребёнок отстаёт») - блокируется Meta. Подход «страх» можно как «не упустить момент развития», но без давления.
- На этапе производства крео - UGC родителей о результате 50% + видео самого процесса (ребёнок на уроке, разрешённый продакшн) 30% + статика-каталог программ 20%. Ребёнок в кадре - только с письменным согласием обоих родителей и без раскрытия имени и школы.
- На этапе аналитики недели - главная метрика cost per attended trial (стоимость состоявшегося пробного урока), не CPL заявки. Промежуточные метрики - 4 CR по слоям воронки (заявка → пробный → ребёнок захотел → оплата). Сезонные множители - август-сентябрь × 0.7 к базовому CPL, январь-март × 0.9, май-июль × 2.

Правки под CRISIS_EXPERT (базовый профиль):
- На этапе ресерча аудитории - транскрипты первичных консультаций (с анонимизацией), отзывы на правовых форумах юрисдикции (для КЗ - Zakon.kz, Adilet.zan.kz; для РБ - Pravo.by; для Украины - Pravda.if.ua, Protocol; для РФ - Pravoved, 9111, опция), судебная практика по теме (для КЗ - Adilet, Sud.gov.kz; для РБ - Pravo.by; для Украины - reyestr.court.gov.ua; для РФ - КонсультантПлюс, опция), профильные telegram-каналы юристов.
- На этапе сегментации - сегментация по стадии кризиса (паника первых дней / разбирается сам и не получается / на пороге дедлайна / уже пропустил срок). Демография не работает - в банкротство приходят и студенты и пенсионеры.
- На этапе подходов / матрицы 4 углов - подходы ЭКСПЕРТНОСТЬ (через стаж, статистику дел, ссылки на статьи кодекса юрисдикции) и СРОЧНОСТЬ (через процессуальные сроки по процессуальным кодексам юрисдикции, не маркетинговую). Подход «страх» через объективную риск-процедуру («по статье X кодекса юрисдикции срок до Y лет»), не пугание. Запрет на гарантии исхода («гарантируем выигрыш дела»).
- На этапе производства крео - юрист talking-head с конкретикой, без эмоциональных трейлеров. Два регистра в разных адсетах: холодный экспертный для верха воронки (на «вы», цифры и закон) и тёплый человеческий для нижнего (на «ты», «давай разберём по шагам»). Бережность из обычного SOFT_EXPERT не применять.
- На этапе аналитики недели - главная метрика cost per consultation (стоимость состоявшейся первичной консультации), CPL заявки вспомогательная.

Под режим накладываются правки на объём и структуру работы:
- Объём ресерча (цитаты, источники).
- Количество сегментов и Schwartz-разметка.
- Количество офферов на сегмент.
- Количество крео-гипотез.
- Структура запуска (ABO / CBO, optimization event, Pixel-only / Pixel+CAPI). Расшифровка, потому что в интерфейсе Meta этих букв нет: **ABO** - бюджет на уровне групп объявлений (задаётся в каждом адсете), **CBO** - в интерфейсе называется **Advantage+ campaign budget**, то есть бюджет на уровне кампании. Ученику в кабинете искать надо именно эти названия, аббревиатуры живут только в жаргоне.
- Окна KILL/HOLD/SCALE.
- Лесенка распределения бюджета 60/30/10 или упрощённая.

## Подпрофили LOCAL_SERVICE

Внутри LOCAL_SERVICE экономика и подход к крео сильно различаются — выбирай подпрофиль вторым полем.

- **HIGH_TICKET_LOCAL_SERVICE** — ремонт квартир под ключ, премиум-стоматология (имплантация, виниры), премиум-косметология, дизайн интерьера. Чек 1500+ USD, цикл сделки 30-90 дней. Экономика как у HIGH_TICKET, но с LOCAL-привязкой к гео. Лид-магнит = бесплатный замер / диагностика / смета, не запись на услугу.
- **LOW_TICKET_RETENTION_LOCAL_SERVICE** — барбершоп, маникюр-педикюр, кофейни, фитнес-клубы. Чек 20-100 USD, главная метрика — LTV и retention. Direct-response крео, гео-привязка, скидка на первый визит, программа лояльности.
- **STANDARD_LOCAL_SERVICE** — общая медицина, обычная стоматология, обычный фитнес, ремонт авто. Дефолт для LOCAL_SERVICE.

## EXECUTIVE_COACHING (подпрофиль HIGH_TICKET)

Отдельный подпрофиль внутри HIGH_TICKET для коучинга руководителей.

- Аудитория: руководители, собственники, топ-менеджеры.
- Регистр: ОПЕРАЦИОННЫЙ, не терапевтический. Язык решений и стратегии, не «бережности и саморазвития».
- Запрещено: формулировки в стиле SOFT_EXPERT («бережная работа», «ты в порядке»), терапевтическая риторика.
- Чек: 500-5000 USD за сессию или пакет.
- Лид-магнит: самооценка управленческой нагрузки, шаблон сложного решения, чек-лист зрелости управленческого стиля.

```
   - Если PRO+FINTECH → предупреждение про предельный CAC, гнать через `reality-check-metrics` с LTV-моделью.
   - Иначе → совместимо, идём дальше.

4. Правки протокола под профиль (этапы ресерча аудитории, сегментации, подходов / матрицы 4 углов, производства крео, аналитики недели) - одним блоком.
   - Если REGISTER=GREY — формат / архетип / угол на этапах подходов и крео перебиваются switch-таблицей регистра; профильный дефолт в таблицах = WHITE-ветка. Указывай это в блоке правок.

5. Правила работы под режим для всех этапов конвейера - одним блоком (объём ресерча, сегменты, офферы, крео, структура запуска, KILL/HOLD/SCALE).

6. Строки для профиля клиента (`00-profile.md`).
   - «Профиль ниши - {профиль}. Обоснование - {краткое}».
   - «Режим конвейера - {режим}. Обоснование - бюджет {Z} USD/мес».
```

## Примеры

Пример 1. KIDS_PARENTS LITE - совместимо.
Вход. Клиент - онлайн-школа казахского для детей в Алматы. Продукт онлайн. Чек 80 USD. Цикл 14 дней. Покупает физлицо (мама ребёнка). Бюджет 350 USD/мес.
Выход.
- Базовый профиль KIDS_PARENTS (двойная воронка ЛПР=мама / пользователь=ребёнок, онлайн-инфопродукт для родителей). Подпрофиль - не выбран. GREY_NICHE: нет. Обоснование - детский онлайн-курс с COPPA/GDPR-K compliance.
- Режим LITE. Обоснование - бюджет 350 USD/мес.
- Совместимо.
- Правки под профиль. На этапе ресерча аудитории - источники Telegram-чаты родителей в Алматы, отзывы конкурентов в Instagram. На этапе сегментации - сегментация по мотиву (наследие/билингвизм/школа). На этапе подходов / матрицы 4 углов - подходы СОЦДОКАЗ и ЭМОЦИЯ. На этапе производства крео - UGC мам 70% + статика 30%. На этапе аналитики недели - CPL основная метрика, ROAS через 21 день.
- Правила под режим LITE. Ресерч 10-15 URL, 2 сегмента, 1-2 в параллельном тесте (предел бюджета, НЕ приоритезация), 6-10 крео общим (по 3-5 на сегмент), 80% UGC + 20% Static. Optimization on ViewContent или PageView, Pixel only приемлем. ABO 14 дней без перехода в CBO. KILL/HOLD/SCALE на основе 7-14 дней. Без лесенки 60/30/10 - победитель ×1.5-2, проигравший убиваем.
- Строки для профиля клиента (`00-profile.md`).
  - «Базовый профиль ниши - KIDS_PARENTS. Подпрофиль - не выбран. Обоснование - детский онлайн-курс с двойной воронкой ЛПР=мама / пользователь=ребёнок».
  - «Режим конвейера - LITE. Обоснование - бюджет 350 USD/мес».

Пример 2. ECOM STANDARD - совместимо.
Вход. Клиент - интернет-магазин косметики, Минск. Продукт онлайн. Чек 45 USD. Цикл 1-3 дня. Покупает физлицо. Бюджет 1100 USD/мес.
Выход.
- Базовый профиль ECOM. Подпрофиль не выбран (стандартный D2C с каталогом). GREY_NICHE: нет. Обоснование - товарный e-commerce с импульсной покупкой и собственной D2C-витриной.
- Режим STANDARD. Обоснование - бюджет 1100 USD/мес.
- Совместимо.
- Правки под профиль. На этапе ресерча аудитории - отзывы с маркетплейсов и Instagram-комментарии конкурентов. На этапе сегментации - сегментация по типу кожи / поводу покупки. На этапе подходов / матрицы 4 углов - подходы ВЫГОДА и СОЦДОКАЗ. На этапе производства крео - 40% статика-каталог + 40% видео-демо + 20% cinematic. На этапе аналитики недели - ROAS основная, CPL вспомогательная.
- Правила под режим STANDARD. Ресерч 20-40 URL, 3-4 сегмента, 2-3 параллельно в тесте, 16-30 крео на сегмент, 40% статика + 40% видео-демо + 20% cinematic. Optimization on Purchase. ABO 7 дней потом CBO. KILL/HOLD/SCALE по ROAS не CPL. Лесенка 60/30/10 облегчённая.
- Строки для профиля клиента (`00-profile.md`).
  - «Базовый профиль ниши - ECOM. Подпрофиль - не выбран. Обоснование - товарный e-commerce с импульсной покупкой».
  - «Режим конвейера - STANDARD. Обоснование - бюджет 1100 USD/мес».

Пример 3. Комбинация со СТОП-разговором.
Вход. Клиент - B2B SaaS для HR-отделов в Армении. Продукт онлайн. Чек 49 USD/мес recurring. Цикл 30-60 дней с демо. Покупает компания. Бюджет 400 USD/мес.
Выход.
- Базовый профиль B2B_SAAS. Подпрофиль не выбран. GREY_NICHE: нет. Обоснование - подписочный B2B-продукт с длинным циклом и обязательным демо.
- Режим LITE. Обоснование - бюджет 400 USD/мес.
- СТОП-разговор. На LITE-бюджете B2B-цикл не запускается. Качественный лид в B2B стоит 30-80 USD, цикл сделки 30-90 дней. На 400 USD/мес ты получишь 0-2 квал-лида в месяц при сделках которые закроются через квартал. Это расчёт, а не запрет: решение за тобой и клиентом, но принимаешь его с открытыми глазами.
- Три варианта решения.
  1. Поднять бюджет минимум до 1500 USD/мес (нижняя граница STANDARD - 500, но для B2B-цикла рабочий минимум 1500).
  2. Сменить нишу на low-ticket версию (SMB-сегмент с чеком до 100 USD/мес и циклом до 14 дней).
  3. Уйти в Pixel-only - органика + ретаргет по существующим контактам, без холодного таргета.
- Профиль клиента (`00-profile.md`) не заполняется, пока ученик не выбрал вариант. Если ученик отвечает «клиент всё равно хочет пробовать на 400» - идём дальше, но в `00-profile.md` строкой: «риск принят: ожидание 0-2 квал-лида/мес, окно оценки квартал, вердикт по CPQL, не по сделкам».

## Edge cases

Когда профиль на стыке двух типов.
- Онлайн-школа с физической точкой (онлайн+офлайн курсы английского) - смотри куда идёт основной поток заявок. Если на онлайн-форму - ИНФОБИЗ. Если на запись в офис - ЛОКАЛЬНЫЙ-СЕРВИС. Если 50/50 - помечай гибрид и работай по ИНФОБИЗ как основной.
- Интернет-магазин с услугой подписки (например косметика по подписке) - ИНТЕРНЕТ-МАГАЗИН с пометкой «recurring», подсегменты под повторные продажи отдельно.
- Премиум-курс от 1500 USD - выбираем между ИНФОБИЗ и ПРЕМИУМ по циклу сделки. Если есть обязательная консультация и созвон - ПРЕМИУМ. Если воронка автоматическая - ИНФОБИЗ.
- B2B-услуга с быстрым закрытием (например агентство таргета с чеком 500 USD/мес и циклом 7 дней) - B2B-СЕРВИС по типу клиента, но применяем правила с оговоркой что CPQL считается на более коротком окне.
- Импульсный e-com (один WOW-товар через Reels) vs обычный ИНТЕРНЕТ-МАГАЗИН - смотри на два маркера: D2C-каталог и повторные покупки. Есть бренд и каталог - ECOM. Один SKU без каталога, retention=0 - ECOM_IMPULSE.
- Медкосметология (контурная пластика, ботокс, лазер) vs тяжёлая медицина - порог по инвазивности и чеку. Чек до 800 USD, амбулаторно, без общего наркоза - SOFT_EXPERT. Чек 2000+ USD, инвазивно, наркоз, госпитализация - MEDICAL_HEAVY.
- Юристы. Юристы-консультанты (обычные споры, договорная работа) - SOFT_EXPERT. Юристы в кризисе клиента (банкротство, развод с разделом, уголовка) - CRISIS_EXPERT как базовый профиль.
- ИНФОБИЗ для детей vs KIDS_PARENTS - смотри кто пользователь. Курс по эмоциональному интеллекту для взрослых женщин - ИНФОБИЗ. Курс программирования для детей 8-14 лет - KIDS_PARENTS (ЛПР родитель, пользователь ребёнок).

Когда бюджет на границе.
- 480-520 USD или 2500-3500 USD - выбирай нижний режим, помечай возможность перехода после первой итерации с подтверждённым ROAS.
- Бюджет указан в валюте с высокой волатильностью (UZS, GEL, AMD) - помечай «при курсе на дату X». Через месяц может смениться режим из-за курса.
- Бюджет ниже 200 USD/мес - LITE, но честно предупредить ученика что на таком бюджете тест 5-7 дней - это весь месяц трафика, окно для решений очень узкое.

Когда блокировать переход на этап ресерча аудитории.
- Базовый профиль не определён после уточнений у ученика - без него корректировки этапов не накладываются, конвейер работает как general INFOBIZ, что неправильно для других вертикалей.
- Комбинация со СТОП-разговором (LITE+B2B_SAAS, LITE+HIGH_TICKET, LITE+MEDICAL_HEAVY) - пока ученик не пересмотрел вводные или не сказал явное «да» с принятым риском, дальше не идём.
- Бюджет не указан в USD - до конкретной цифры режим не определяется.

## Quality-gate

Перед выдачей проверь.
- Базовый профиль выбран ровно один из 10 канонических (INFOBIZ / LOCAL_SERVICE / ECOM / B2B_SAAS / HIGH_TICKET / CRISIS_EXPERT / REAL_ESTATE_EXPAT / WELLNESS_HEALTH_RESTRICTED / KIDS_PARENTS / ECOM_IMPULSE). Не «INFOBIZ или ECOM».
- Подпрофиль явно помечен где применим (формат «BASE + специфика»): HIGH_TICKET_LOCAL_SERVICE, HIGH_TICKET_PRO_SERVICES, LOW_TICKET_RETENTION_LOCAL_SERVICE, STANDARD_LOCAL_SERVICE, EXECUTIVE_COACHING, EXECUTIVE_COACHING_PREMIUM, ECOM_PROSTOY, ECOM_PREMIUM, HIGH_TICKET_ECOM, ECOM_MARKETPLACE_SELLER, MEDICAL_HEAVY, SOFT_EXPERT, B2B_PROFESSIONAL_SERVICES, B2B_SAAS_ENTERPRISE, B2B_SAAS_SMB, WELLNESS_HEALTH_RESTRICTED_USA, FINTECH, SUBSCRIPTION_BOX, RELIGIOUS_TRAVEL. Если ни один не применим — пиши «не выбран».
- Overlay проставлен явно: EU_RUSSIAN_DIASPORA / INFOBIZ_DOHOD / нет. Overlay идёт дополнительно к подпрофилю, не вместо. Если в оффере есть employment/income-фрейм, а INFOBIZ_DOHOD не стоит — выдача не закрыта.
- GREY_NICHE флаг проставлен явно (да/нет).
- Строка «Регистр: WHITE / GREY» выведена явно. Дефолт WHITE не «подразумевается» — он пишется строкой.
- Строка «Special Ad Category: HOUSING / EMPLOYMENT / FINANCIAL PRODUCTS & SERVICES / ISSUES, ELECTIONS AND POLITICS / нет (гео вне US-CA-EU)» выведена явно. Сначала проверено гео: на чистом СНГ-таргете пишем «нет (гео вне US-CA-EU)» и таргет НЕ сужаем искусственно. При флаге HOUSING / EMPLOYMENT / FINANCIAL PRODUCTS & SERVICES рядом стоит пометка про широкий таргет + таргет креативом и про недоступность lookalike; при ISSUES, ELECTIONS AND POLITICS - про верификацию и «Paid for by». Нет строки - выдача не закрыта.
- Сегмент Жертвы как приоритетный отсутствует — проверь по маркерам из блока «ЖЁСТКИЙ ЗАПРЕТ» в начале файла.
- Режим выбран ровно один из 3 (LITE / STANDARD / PRO). Не «LITE/STANDARD».
- Совместимость пары проверена явно - либо «совместимо», либо «СТОП-разговор + расчёт + 3 варианта», либо «предупреждение». Если был СТОП-разговор и ученик сказал «идём» - в выдаче стоит строка с риском, который записан в `00-profile.md`.
- Правки под профиль покрывают этапы ресерча аудитории, сегментации, подходов / матрицы 4 углов, производства крео и недельной аналитики - не пропущены.
- Правила под режим покрывают объём ресерча, сегменты, офферы, крео, структуру запуска, KILL/HOLD/SCALE.
- Две строки для профиля клиента (`00-profile.md`) готовы к копированию.
- Если был СТОП-разговор и вводные не пересмотрены и явного «да» ученика нет - профиль клиента (`00-profile.md`) не заполняется, стоит явная пометка «ждём решения ученика по трём вариантам».

## Когда не работаешь

При повторном вызове в том же чате если пара уже зафиксирована и вводные не менялись - не дублируем.

При расчёте предельного CPL по экономике клиента - это `reality-check-metrics`.

При вопросе на знание «что такое LITE» / «чем ECOM отличается от INFOBIZ» без своего клиента - это `ru-marketer` или прямая ссылка на Часть 4 (бюджетные режимы) и Часть 3 (профили ниш) KONVEYER-LOGIKA.md.

При составлении чек-листа запуска Meta под выбранный режим - это `meta-launch-checklist`.

При сборке стратегии и сегментации после определения профиля - это `ru-marketer` → `research-structurer`.

Полный канон профилей и режимов: KONVEYER-LOGIKA.md, Часть 3 «Профили ниш» и Часть 4 «Бюджетные режимы» — там 10 базовых (включая KIDS_PARENTS и ECOM_IMPULSE), GREY_NICHE надстройка и иерархия подпрофилей.
