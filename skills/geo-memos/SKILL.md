Это не процессный скил, а набор из трёх reference-памяток по гео-специфике рынков и лёгкий роутер над ними. Своей методики скил не содержит - вся работа идёт по содержимому памятки. Открой нужный файл рядом и применяй для клиента с этого рынка:

- **Украина 2026** → `ukraine-2026.md` — тон, военная тема, блэкаут, технические особенности.
- **DACH B2B (DE / AT / CH) на Meta** → `dach-b2b-meta.md` — Custom Audience из CRM, 5-роль buying committee, GDPR / FINMA / BaFin.
- **US / Canada wellness** → `us-canada-wellness-compliance.md` — FTC + iOS ATT, Health Canada, CASL, PIPEDA.

Памяток по другим рынкам в скиле нет - в том числе по Казахстану, Беларуси, Узбекистану и UK. Спрашивают про рынок, которого нет в списке выше - скажи об этом прямо: «памятки по этому рынку нет». Локальные правила, лицензии и запреты НЕ выдумывай и не переноси по аналогии с соседней страной.

Цифры внутри памяток - ориентиры рынка на дату памятки, а не бенчмарк. Называешь цифру клиенту - помечай, откуда она.
