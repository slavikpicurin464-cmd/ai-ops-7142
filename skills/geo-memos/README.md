# Geo-памятки

Reference-памятки по гео-специфике рынков. Рядом — лёгкий `SKILL.md`-роутер (чтобы папка валидировалась как скил при установке плагина и памятки были вызываемы); сам контент — в `.md`-файлах ниже.

На памятки ссылаются два скила пакета:
- `meta-launch-checklist` - блок EU compliance ссылается на `dach-b2b-meta.md`.
- `meta-policy-checker` - пять мест: три ссылки на `ukraine-2026.md` (локальные требования к рекламе лицензируемых услуг, адвокатская монополия и юрисдикции, UA-аудитория и релоканты) и две на `us-canada-wellness-compliance.md` (US wellness-пресет и состав гео-оговорок).

Больше на памятки не ссылается никто.

## Когда использовать

Подгружай нужную памятку при работе с клиентом из соответствующего рынка - до запуска кампаний, при разборе крео, при формировании офферов.

## Список памяток

- [ukraine-2026.md](./ukraine-2026.md) - Украина 2026. Тон, военная тема, блэкаут, технические особенности.
- [dach-b2b-meta.md](./dach-b2b-meta.md) - DACH B2B (Германия / Австрия / Швейцария) на Meta. Custom Audience из CRM, 5-роль buying committee, GDPR/FINMA/BaFin compliance.
- [us-canada-wellness-compliance.md](./us-canada-wellness-compliance.md) - US / Canada wellness. FTC, трекинг на iOS, Health Canada, CASL, PIPEDA.

Других памяток в скиле нет. По Казахстану, Беларуси, Узбекистану и UK памяток не написано - правила по этим рынкам не выдумываем и по аналогии с соседями не переносим.
